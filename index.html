02 — MATEMÁTICA

A matemática das senhas

Quanto maior for a quantidade de caracteres e combinações, maior será o número de possibilidades.

📐 Fórmula

Podemos representar o número de combinações possíveis usando:

NL

N = quantidade de caracteres disponíveis

L = tamanho da senha

🔢 Exemplo

Se uma senha possui 8 posições e utiliza 26 letras minúsculas:

268

Isso representa mais de 200 bilhões de combinações possíveis.

🛡️ Segurança

Adicionar letras maiúsculas, números, símbolos e aumentar o tamanho da senha aumenta o número de combinações possíveis.

03 — ANÁLISE CRÍTICA

Comparação de senhas

Observe a diferença entre uma senha previsível e uma senha com maior variedade de caracteres.

⚠️ Senha previsível

senha123
  • É curta.
  • Possui uma palavra comum.
  • Possui uma sequência previsível.
  • Pode ser mais fácil de adivinhar.

🛡️ Senha mais resistente

M7!qZ2#vLp9@Kx
  • Possui mais caracteres.
  • Combina letras maiúsculas e minúsculas.
  • Possui números.
  • Possui símbolos.
